# Changelog

Alfred reads this to tell you what is new when he offers an update. One short line per change.

## 0.19.0
- Updates himself: checks for a new version once a day, says what is new, and installs it when you agree
- "/alfred update" installs the latest version; "/alfred update check" only looks

## 0.18.0
- Searches the web and reads public pages without asking permission each time

## 0.17.0
- Chooses the model for the task: Sonnet for everyday work, his counsel on Opus for complex work

## 0.16.0
- A much wider vocabulary: greetings, confirmations and reminders no longer repeat themselves
- Groundwork for voice ID (not switched on yet)

## 0.15.1
- The Hub opens faster at the start of a session

## 0.15.0
- Windows control: volume, media keys, open apps and sites, screenshot, lock screen, battery
- Reminders, timers and scheduled requests
